# DINA.MEDIA

Portfolio website for Dina, a social media manager and content creator based in Algeria, working remotely.

## What's on the site
- About and services
- Portfolio with filters: reels and video, photos and design, AI generated
- Process, testimonials and FAQs
- Contact via WhatsApp, email and Instagram (@dina.media)

## How it works
The whole site is one file: `index.html`. No installation or build step is needed.

## Edit the content
Open `index.html`, find the section marked `EDIT ME` in the script, and change the email, services, projects and process steps.

## Publish
Turn on GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
